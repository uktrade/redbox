Accessibility statement for {{ productName }}

This accessibility statement applies to {{ productName }}.

This website is run by the {{ departmental_owner }}. We want as many people as possible to be able to use this website. For example, that means you should be able to:

  • change colours, contrast levels and fonts using browser or device settings
  • zoom in up to {{ zoom_level }} without the text spilling off the screen
  • navigate most of the website using a keyboard or speech recognition software
  • listen to most of the website using a screen reader (including the most recent versions of JAWS, NVDA and VoiceOver)

We've also made the website text as simple as possible to understand.

AbilityNet has advice on making your device easier to use if you have a disability.

How accessible this website is

We know some parts of this website are not fully accessible:

  • Some text and page elements are difficult to see because they do not have enough colour contrast
  • Some pages do not work well when zoomed in, and users may need to scroll in more than one direction or may lose access to content and features
  • Some headings, labels and keyboard navigation features are unclear or difficult to use, which can make it harder to find information and move around the site

Feedback and contact information

If you find any problems not listed on this page or think we're not meeting accessibility requirements, contact {{ contact_email }}.

If you need information on this website in a different format like accessible PDF, large print, easy read, audio recording or braille, email {{ contact_email }}.

We'll consider your request and get back to you in 14 days.

Enforcement procedure

The Equality and Human Rights Commission (EHRC) is responsible for enforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018 (the "accessibility regulations"). If you're not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS).

Non-accessible content

The content listed below is non-accessible for the following reasons.

Non-compliance with the accessibility regulations

  • Some text is difficult to read because there is not enough colour contrast between the text and the background. This fails WCAG 2.2 success criterion 1.4.3 (Contrast (Minimum))
  • Some buttons, icons and other page elements are difficult to see because there is not enough colour contrast. This fails WCAG 2.2 success criterion 1.4.11 (Non-text Contrast)
  • Some content does not work well when zoomed in. Users may need to scroll in more than one direction or may not be able to access all content and features. This fails WCAG 2.2 success criterion 1.4.10 (Reflow)
  • Some headings and labels do not clearly explain their purpose, making it harder to find information and use the website. This fails WCAG 2.2 success criterion 2.4.6 (Headings and Labels)
  • The keyboard focus indicator is not always visible because it can be covered by other page content, making it harder for keyboard users to navigate the website. This fails WCAG 2.2 success criterion 2.4.11 (Focus Not Obscured (Minimum))
